## 1. Введение и концепция проекта

### 1.1. Назначение системы

Разработка легковесной, высокопроизводительной веб-платформы для подготовки студентов к участию в программе академического обмена Госдепартамента США (**SPARK 2027**) и смежных грантовых треках (включая программу **INSPIRE**).

### 1.2. Ключевые бизнес-параметры

| Параметр | Значение |
| :--- | :--- |
| **Базовая стоимость продукта** | 3 тарифа участия: Базовый (2 900 ₽), Акселератор (6 900 ₽), VIP (14 900 ₽) (скидка 5% по промокоду) |
| **Формат обучения** | Асинхронные модули (видео + текст + чеклисты) + персональный аудит эссе/резюме автором + 1 мок-интервью в Zoom (45 минут) + личный чат поддержки |
| **Бонусный трек INSPIRE** | Доступен за дополнительную плату (акселератор для удвоения шансов) |
| **Канал обратной связи** | Прямая коммуникация со студентами через Telegram-аккаунт/бот куратора `@spark_prep_bot` |
| **Юридический статус** | Самозанятый Иль О. В. (так называемый Иль) (ИНН: `780739313219`, НПД, чеки ФНС «Мой налог») |
| **Хостинг видео** | YouTube (доступ по закрытой ссылке / Unlisted) с обфускацией в кастомном защищённом плеере |
| **Инфраструктура** | Единый `docker-compose` контур (Go-бэкенд API, отдельный сервис Telegram-бота `spark_bot`, Next.js 14 фронтенд, PostgreSQL 16, Caddy Server) |

## 2. Дизайн-система и UI/UX спецификация: "Spatial Bento-Glass"

> *Дизайн-система проекта построена на концепции **Spatial Bento-Glass (Dark Obsidian)** — глубокий космический обсидиановый фон, матовый пространственный глассморфизм, модульные Bento-сетки, неоновые и янтарные микро-акценты, кинематографичные эдиториал-фотографии.*

### 2.1. Цветовая палитра и тональность (Dark Obsidian)

* **Базовый фон:** Глубокий графитово-обсидиановый `#121316` (сохраняет фокус на контенте и контрастность).
* **Поверхности Bento (Surfaces):**
  * `bento-card-dark`: `background: rgba(24, 26, 32, 0.75)`, `backdrop-filter: blur(28px)`, тонкая обводка `1px solid rgba(255, 255, 255, 0.15)` – `0.25`, мягкое внутреннее свечение `inset 0 1px 1px rgba(255, 255, 255, 0.15)`.
  * `bento-nav-pill`: плавающая пилюля навигации `background: rgba(18, 19, 22, 0.85)`, `backdrop-filter: blur(24px)`, обводка `1px solid rgba(255, 255, 255, 0.2)`.
* **Типографическая гамма:**
  * Заголовки (H1, H2, H3): Чистый белый `#FFFFFF` (для Hero-заголовка и подзаголовка применён drop-shadow для максимальной читаемости поверх фотографии).
  * Второстепенный текст: `#F8F9FA`, `text-slate-300`, `text-slate-400`.
* **Акцентные маркеры:**
  * **Amber / SPARK Orange:** `#F59E0B`, `#FF7A00` — акцентные бейджи, хотспоты кампуса Вайоминга, отметка «за доп. плату».
  * **Emerald:** `#10B981`, `#34D399` — метки верификации (`J-1 Visa Approved`), успешные чеки, статус раннего бронирования.
  * **Sky / Cobalt:** `#38BDF8`, `#2563EB` — теги программ, технологические метки.
  * **Rose:** `#F43F5E` — бейдж дефицита мест (`25 мест на поток • Осталось: 9 мест`).

### 2.2. Типографика

* **Display / Hero Font:** *Plus Jakarta Sans* / *Manrope* (Bold / Extrabold, плотный отрицательный трекинг: `-0.02em` до `-0.03em`, полная поддержка кириллицы).
* **Accent / Monospace Numerals:** *Space Grotesk* для индексных номеров (`01`, `02`, `03`), ценовых блоков (`6 900 ₽`) и экзаменационных результатов (`C1 - 135 DET`).
* **Body / UI Font:** *Manrope* / *Inter* (13px–15px для микро-копирайтинга, 16px–18px для основного текста).

## 4. Функциональные требования: пользовательская часть

### 4.1. Авторизация через Telegram

* **Desktop / Mobile Web:** Telegram Login Widget с валидацией HMAC-SHA256 хеша на бэкенде и выдачей HttpOnly JWT-сессии.

### 4.2. Формат доставки контента: закрытый Telegram-канал и чат

* Доступ ко всем материалам, гайдам, видеоразборам и базе шаблонов осуществляется через закрытый приватный Telegram-канал и комьюнити-чат по персональной инвайт-ссылке.
* Автоматическая или ручная активация доступа куратором в админ-панели сразу отправляет студенту персональное приглашение в закрытый канал (`https://t.me/+spark_prep_private`).

## 5. Партнёрская (реферальная) система (`/partner`)

* **Модель:** двухуровневая реферальная сеть:
  * **1-й уровень:** 15% (1 035 ₽ с каждой прямой оплаты по реферальной ссылке);
  * **2-й уровень:** 5% (345 ₽ со второго уровня).
* **Трекинг:** Клиентский компонент `ReferralTracker.tsx` считывает `?ref=...`, сохраняет реферера в `localStorage` и `cookies` на 30 дней.
* **Кабинет `/partner`:**
  * Генератор и копирование персональной ссылки `https://sparkprep.ru/?ref=USERNAME`;
  * Интерактивный калькулятор дохода (3 друга = 3 105 ₽, 5 друзей = 5 175 ₽, 10 друзей = 10 350 ₽);
  * Заказ выплат на карту РФ или СБП (от 1 000 ₽).

## 6. Панель администратора (`/admin`)
 
* **Безопасная аутентификация куратора:** Защита по паре логин/пароль (`ADMIN_USERNAME` / `ADMIN_PASSWORD`), исключающая брутфорс PIN-кодов, с выдачей защищённого JWT-токена с ролью `role: "admin"`.
* **Комплексная защита от атак (Rate Limiting & Security Shield):**
  * **Brute-Force Rate Limiting:** строгое ограничение попыток входа на эндпоинт `/api/v1/admin/login` (максимум 5 запросов в минуту с одного IP). При превышении возвращается `HTTP 429 Too Many Requests` с заголовком `Retry-After: 60`.
  * **Обратный отсчёт блокировки на фронтенде:** `AdminLogin.tsx` перехватывает 429-код и запускает посекундный таймер ожидания с блокировкой кнопки отправки.
  * **Timing Attack Mitigation:** проверка логина и пароля в Go через `crypto/subtle.ConstantTimeCompare`, исключающая утечку данных через замер времени ответа сервера.
  * **Artificial Latency Penalty:** принудительная задержка в 1 секунду при неверных реквизитах входа.
  * **Общий Rate Limiting API:** скользящее окно 120 запросов/мин на всю группу `/api/v1/*` для защиты от парсеров и флуда.
  * **Ограничение размера тела запроса:** лимит 2 МБ в Gin и 5 МБ в Caddy для исключения DoS через память.
  * **Enterprise HTTP Security Headers:** `X-Content-Type-Options: nosniff`, `X-Frame-Options: SAMEORIGIN`, `Referrer-Policy: strict-origin-when-cross-origin`, `Permissions-Policy`.
  * **Блокировка сканеров уязвимостей в Caddy:** мгновенный возврат 403 Forbidden для запросов к `.env`, `.git`, `wp-*`, `admin.php`, `*.sql`.
* **Двухкомпонентная модульная структура (табы):**
  1. **[📊 Студенты и доступы]:**
     * Аналитические KPI: общая выручка, количество активных студентов, конверсия из регистраций в оплату, сумма и количество заявок на выплату.
     * Быстрый поиск студентов по имени, никнейму или Telegram ID.
     * Мгновенный 1-click тумблер активации доступа (`has_access = true`), автоматически распределяющий 15%/5% комиссионных партнёрам и отправляющий приглашение в закрытый Telegram-канал.
  2. **[💰 Выплаты партнёрам]:**
     * Список входящих заявок на вывод средств рефералов (СБП, номер телефона, банк).
     * 1-click подтверждение выплаты или отклонение с возвратом средств на баланс партнёра.

## 7. Telegram-бот и воронки

1. **Архитектура:** Бот работает как **независимый standalone-сервис** (`cmd/bot/main.go`, контейнер `spark_bot`), изолированный от HTTP API сервера, что гарантирует бесперебойную обработку команд пользователей и воронки при технических работах на сайте.
2. **Обработка Deep Link:** `/start ref_CODE` фиксирует реферальную связь.
3. **Лид-магнит воронка:**
   * На сайте: модальное окно `LeadMagnetModal.tsx`:
     > **«Анатомия заявки на $20,000»**  
     > *Видеоразбор заявки финалиста SPARK 2026 + PDF-чеклист по эссе*
   * Переход в бота `@spark_prep_bot?start=guide_essay` с выдачей материалов.
4. **Оплата через бота:**
   * При заполнении `PaymentModal.tsx` генерируется ссылка `@spark_prep_bot?start=pay_USERNAME` для завершения оплаты и получения чека.
5. **Фоновые уведомления:** об успешной активации доступа куратором, начислении 15%/5% партнёрских комиссионных и одобрении выплат.

## 8. Схема базы данных (PostgreSQL)

```sql
CREATE TABLE users (
    id BIGSERIAL PRIMARY KEY,
    telegram_id BIGINT UNIQUE NOT NULL,
    username VARCHAR(64),
    first_name VARCHAR(128) NOT NULL,
    last_name VARCHAR(128),
    photo_url TEXT,
    role VARCHAR(20) DEFAULT 'student',
    has_access BOOLEAN DEFAULT FALSE,
    access_granted_at TIMESTAMP WITH TIME ZONE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE TABLE referrals (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT UNIQUE REFERENCES users(id) ON DELETE CASCADE,
    referred_by_id BIGINT REFERENCES users(id) ON DELETE SET NULL,
    parent_referrer_id BIGINT REFERENCES users(id) ON DELETE SET NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE TABLE affiliate_profiles (
    user_id BIGINT PRIMARY KEY REFERENCES users(id) ON DELETE CASCADE,
    referral_code VARCHAR(32) UNIQUE NOT NULL,
    current_balance NUMERIC(10, 2) DEFAULT 0.00 CHECK (current_balance >= 0),
    total_earned NUMERIC(10, 2) DEFAULT 0.00,
    total_withdrawn NUMERIC(10, 2) DEFAULT 0.00
);

CREATE TABLE referral_transactions (
    id BIGSERIAL PRIMARY KEY,
    affiliate_id BIGINT REFERENCES users(id),
    buyer_id BIGINT REFERENCES users(id),
    level INT NOT NULL CHECK (level IN (1, 2)),
    amount NUMERIC(10, 2) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE TABLE payout_requests (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT REFERENCES users(id) ON DELETE CASCADE,
    amount NUMERIC(10, 2) NOT NULL CHECK (amount >= 1000),
    payment_details TEXT NOT NULL,
    status VARCHAR(20) DEFAULT 'pending',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    resolved_at TIMESTAMP WITH TIME ZONE
);

CREATE TABLE modules (
    id SERIAL PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    description TEXT,
    order_index INT NOT NULL DEFAULT 0,
    is_published BOOLEAN DEFAULT TRUE
);

CREATE TABLE lessons (
    id SERIAL PRIMARY KEY,
    module_id INT REFERENCES modules(id) ON DELETE CASCADE,
    title VARCHAR(255) NOT NULL,
    content_markdown TEXT NOT NULL,
    youtube_video_id VARCHAR(64),
    resources JSONB DEFAULT '[]'::jsonb,
    order_index INT NOT NULL DEFAULT 0,
    is_published BOOLEAN DEFAULT TRUE
);

CREATE TABLE user_progress (
    user_id BIGINT REFERENCES users(id) ON DELETE CASCADE,
    lesson_id INT REFERENCES lessons(id) ON DELETE CASCADE,
    completed_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    PRIMARY KEY (user_id, lesson_id)
);
```

## 9. Конфигурация деплоя и инфраструктуры

```yaml
version: '3.8'

services:
  caddy:
    image: caddy:2-alpine
    container_name: spark_caddy
    restart: unless-stopped
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./Caddyfile:/etc/caddy/Caddyfile:ro
      - caddy_data:/data
      - caddy_config:/config
    depends_on:
      - backend
      - frontend

  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    container_name: spark_backend
    restart: unless-stopped
    environment:
      - PORT=8080
      - DATABASE_URL=postgres://spark_user:StrongPassword2026@postgres:5432/spark_db?sslmode=disable
      - TELEGRAM_BOT_TOKEN=${TELEGRAM_BOT_TOKEN}
      - JWT_SECRET=${JWT_SECRET}
      - ADMIN_TELEGRAM_ID=${ADMIN_TELEGRAM_ID}
      - ADMIN_USERNAME=${ADMIN_USERNAME:-admin}
      - ADMIN_PASSWORD=${ADMIN_PASSWORD:-SparkAdmin2026!}
      - DOMAIN=sparkprep.ru
    depends_on:
      postgres:
        condition: service_healthy

  bot:
    build:
      context: ./backend
      dockerfile: Dockerfile
    container_name: spark_bot
    restart: unless-stopped
    command: ["/app/spark-bot"]
    environment:
      - DATABASE_URL=postgres://spark_user:StrongPassword2026@postgres:5432/spark_db?sslmode=disable
      - TELEGRAM_BOT_TOKEN=${TELEGRAM_BOT_TOKEN}
      - DOMAIN=sparkprep.ru
    depends_on:
      postgres:
        condition: service_healthy

  frontend:
    build:
      context: ./frontend
      dockerfile: Dockerfile
    container_name: spark_frontend
    restart: unless-stopped
    environment:
      - NEXT_PUBLIC_API_URL=https://sparkprep.ru/api/v1
      - NEXT_PUBLIC_BOT_USERNAME=spark_prep_bot

  postgres:
    image: postgres:16-alpine
    container_name: spark_postgres
    restart: unless-stopped
    environment:
      POSTGRES_USER: spark_user
      POSTGRES_PASSWORD: StrongPassword2026
      POSTGRES_DB: spark_db
    volumes:
      - pgdata:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U spark_user -d spark_db"]
      interval: 5s
      timeout: 5s
      retries: 5
```
